# ملفات GitHub Pages

ارفع **محتويات المجلد ده** (مش المجلد نفسه) على جذر الريبو:

- `pdr-filter.js`
- `pdr-filter.css`
- `index.html`
- `.nojekyll` (مهم — يمنع معالجة Jekyll)

بعد تفعيل Pages، الروابط بتكون:

```
https://USERNAME.github.io/REPO/pdr-filter.js
https://USERNAME.github.io/REPO/pdr-filter.css
```

## التحديث

- عدّل `pdr-filter.js` (أو ارفع نسخة جديدة مكانه) → Commit.
- GitHub Pages يعيد النشر خلال 1-2 دقيقة.
- المستخدم يعمل Refresh؛ الـ Loader بيطلب `?v=timestamp` فبيجيب النسخة الجديدة.

## ملاحظات

- الكود مفيهوش أسماء موظفين؛ القائمة بتتبني من الصفحة وقت التشغيل.
- الريبو public والكود ظاهر؛ راجع سياسة الشركة قبل النشر.
